Containers vs Basic Types

Definition

A data structure is a way to organize data that we wish to process with a computer program. Basic types (integers, floating points, boolean, characters) hold a single value; containers (strings, lists, tuples, dictionaries) hold multiple values.

Lists

Definition

A list is a contiguous block of memory containing multiple values, not all of the same type. It solves the problem of having many variables. Python's list is not the same as an array.

Zero-based Indexing

Python is zero-based

With zero-based indexing (index-0), the index of the last element is one less than the total number of elements. With one-based indexing (index-1), used by some other languages, the index of the last element is the same as the total number of elements.

Tuples and Strings

Tuple

A fixed list of elements, written as comma-separated objects within the parentheses ( and ). Once a tuple is created, you cannot add, delete, or replace any element accidentally.

Mutable vs immutable

Lists are mutable: elements can be modified after creation. Tuples are immutable: like string objects, once created their elements cannot be modified. Tuples are used to pass multiple values out of a function to reduce the risk of modifying the return values. Shared read operations: length with len(s), the i-th item from origin 0 such as tutors[1], and slices from index i to j-1 such as tutors[1:2].

Why does the lecture suggest tuples for a function's return values?
Immutability reduces the risk of the returned values being modified
Tuples support more operations than lists

Dictionaries and Command Line Arguments

Dictionary

Stores data values in key:value pairs. A collection which is ordered (since Python 3.7), changeable, and does not allow duplicates. Items are referred to by the key name, e.g. marks_hw["2134"]. Create one with curly braces { } or the dict() method.

sys.argv

Inputs can be passed in through the command line instead of the input() function. They are stored in argv in the module sys as an array of string objects, and the first element is always the script name. Example: python3 battles.py rostam.
