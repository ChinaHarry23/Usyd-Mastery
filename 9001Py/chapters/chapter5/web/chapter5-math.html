Loop Anatomy

Definition

A loop repeats a set of statements while a condition holds. The lecture's anatomy has four parts: initialize the loop control variable, test it, execute the statement(s) in the body, and modify the loop control variable before testing again.

Race example

Run around the track five times: round = 1 (initialize), round <= 5 (test), RUN!!! (body), round += 1 (modify). The shorthand i += 1 means the same as i = i + 1.

Which component runs immediately before the condition is re-tested?
Modification of the loop control variable
Initialization of the loop control variable

while Syntax & Trace

Syntax

while <boolean expression>: followed by indented Statement(s). The body runs while the expression is True; when it evaluates to False, execution continues after the loop.

RUN!!! program

i = 1; while i <= 5: print(f"Round {i}: RUN!!!"); i = i + 1 prints Round 1 through Round 5, and the final print(f"Round {i}: Stop!") outside the loop prints Round 6: Stop! because i was incremented to 6 before the test failed.

After the RUN!!! loop finishes, what is the value of i?
6
5

Infinite Loops

Definition

A loop that never exits is called an infinite loop. This happens because the condition is always True. If it is unintentional — you didn't design it — issue a Keyboard Interrupt command <CTRL-C> to stop execution.

Prevention tips

Ensure the body contains statements to modify the loop control variable, OR statements to terminate the loop when the event is achieved. A missing modification is a logic error: wrong number of loops at best, infinite loop at worst.

Your program is stuck in an unintentional infinite loop. What does the lecture tell you to do?
Press CTRL-C to issue a Keyboard Interrupt
Wait — Python stops loops automatically after a while

Sentinels and Flags

Sentinel value

An unlikely value that the data can take; receiving it ends the loop. The lecture compares it to a safe-word in extreme haunted houses — never confused with normal input.

Flag

A boolean that controls the loop. The echo program initialises stop_flag = False, loops on not stop_flag, and the body sets stop_flag = True when the user enters the sentinel "STOP IT!". Lecture advice: use a flag to make your code clearer, if it makes it clearer.

In the echo program, what actually stops the loop?
The body sets stop_flag = True after the user types "STOP IT!", making the condition False
The input() function refuses to run more than a fixed number of times
