Selection Statements

Definition

A program with decisions instructs the computer to perform a set of actions depending on whether a condition is fulfilled. The lecture names three selection statements: conditional execution (if), alternative execution (if-else) and chained conditionals (if-elif).

Which selection statement does the lecture prescribe when there are more than two possibilities and you need more than two branches?
if-else
if-elif

if / else Syntax

Patterns

if <Boolean_expression>: followed by an indented statement runs the statement only when the expression is True. Adding else: with a second indented statement guarantees that exactly one of the two branches runs.

Warning from the slide

DO NOT put expressions after the keyword else. An else carries no condition of its own.

The pass statement

pass is a null statement, i.e. do nothing — a placeholder for when a statement is syntactically required but no code needs to be executed.

What belongs immediately after the keyword else?
Just a colon — else takes no condition
Another boolean expression

elif Rules

From the if … elif slide

elif is an abbreviation of else-if. There is no limit on the number of elif statements. If there is an else clause, it has to be at the end, but it is not syntactically required. Conditions are checked in order of appearance, and only the first true branch runs.

The speeding-fine chain

if speed <= 60: fine = 0, then elif checks at 70 (109), 80 (254), 90 (835), and an else of 2252. Slide activity answers: speed −800 → 0, speed 90 → 835, speed 95 → 2252.

In the speeding-fine chain, speed is 90. Which branch runs?
elif speed <= 90, so fine = 835
else, so fine = 2252

Desk Checks

Method

A desk check tracks each variable’s value and how it changes as you walk through the code by hand. Test by picking values that are normal, abnormal, and on the boundary.

Fuel warning example

Start with airConPower = 0.8, fuel = 3.5, fuelWarning = False. The branch if fuel < 5 sets fuelWarning = True and airConPower = 0.5; otherwise airConPower = 1.0. With fuel at 3.5 the warning fires; at the boundary value 5 the else runs instead — checking 0 and 5 is exactly the lecture’s point about boundary testing.
