The Tailor Story: Why Variables?

Lecture motivation: a tailor records customer measurements (Hips, Pant Waist, Thigh, Pant Length) in a notebook. His first program, tailor1.py, prints every value as hard-coded text inside print() calls — the data lives nowhere except inside the strings.

#tailor 1 print("details of Armin Chitizadeh with customer ID of 3322445") print("Customer Name:", "Armin Chitizadeh") print("Customer ID:", "3322445") print("Hips: ", "100") print("Pant Waist: ", "95") print("Thigh: ", "25", sep=" ") print("Pant Length: ", "110", sep=" ")

In life, details change

The lecture shows the same customer years later: Hips 100 → 120, Pant Waist 95 → 100, Thigh 25 → 28, Pant Length 110 → 139. With hard-coded strings, every affected print() line has to be found and edited by hand.

The fix: tailor2.py

Store each measurement once in a named variable, then reuse the name everywhere. When a value changes, you update one assignment line instead of hunting through the whole program.

customer_name = "Armin Chitizadeh" customer_id = "3322445" hips_size = 120 pant_size = 100 thigh = 28 pant = 139 print("details of", customer_name, "with customer ID of", customer_id) print("Hips: ", hips_size, sep=" ")
Key idea: the tailor story is the lecture’s answer to “how can we fix the issue of changing values?” — give the data a name and refer to the name.

Variables: Named Containers

Lecture definition: the simplest definition of a variable is a “named container” of data you’d like to refer to in your program. Variables contain data so you can call it later — this makes data reusable, recallable and re-assignable.

Two reasons to name your data

1. Data usually tends to be bigger than a few characters — imagine calling books by their whole content (possibly hundreds of pages) instead of their names. 2. You will refer to your data multiple times in a program, so it helps to keep it in a convenient container and call it whenever needed, such as when you want to print it.

Declare → Initialise → Use

Before you can use a variable, you must first declare it and initialize it. The lecture illustrates the flow with a C-style example: int total; then total = 0; then total = total + 5;.

Language styleWhen the type is fixedLecture point
Static-typed (e.g. C)At declarationOnce a variable of a specific type is declared, it cannot be assigned a different data type
Dynamically-typed (Python)At run-timeProgrammers can re-assign a variable to a different data type after it is initialized
Type annotation: Python does not require you to declare a type, but you can annotate it to indicate what the variable contains: x: int = 10. The type is still determined at runtime.

Variable Naming Rules

Hard rules

Names must start with a letter (they cannot start with numbers) and must not contain spaces. Python is case sensitive: X and x refer to two different variables. Avoid reserved keywords — words that have a special purpose in the language.

Lecture conventions

Name variables to describe the purpose of the value. ALL CAPS indicates constants, e.g. FLAT_RATE (the tailor programs use FIXED_COST = 40). Lowercase words separated by underscores improve readability. Avoid names that already exist as Python objects, e.g. print, int, str.

False class finally is return None continue for lambda try True def from nonlocal while and del global not with as elif if or yield assert else import pass break except in raise
No memorising needed: the lecture says you do not need to memorize the keyword list — most development environments highlight these keywords in a different colour.

Data Types and Objects

Lecture definition: a data type is a set of values and a set of operations defined on those values. Operators are the representation of a data-type operation and can be unary, binary or ternary.

Primitive types

Primitive types are basic data types that use a fixed amount of memory. The usual examples are int, float, str and bool.

Objects

Objects are blocks of memory that contain related data and the associated operations for that data. One object can contain many other objects, and operators can be customised by the programmer. In Python, everything is an Object!

int, float and Type Casting

Initialising a float

Float variables can be initialized using a sequence of digits with a decimal point or in scientific notation: pi = 3.14159, random_float = 6.02e23. Floats typically have 15–17 decimal digits of precision.

Floats are approximations

Floating-point numbers are approximations of the real numbers, so the lecture warns: be careful when performing comparisons with floating-point numbers. Arithmetic operators work on floats too, but results stay float due to implicit type casting.

>>> 5.0 + 3.0 8.0 >>> 5.0 - 3.0 2.0 >>> 5.0 * 3.0 15.0 >>> 5.0 / 3.0 1.6666666666666667
ConversionHow it happensLecture examples
ExplicitInvoked using function callsstr() converts to type str, int() converts into type int, float() converts into type float
ImplicitPython does the conversion automatically when appropriateResults become float for: division between a float and int, division between two int, addition between an int and float

Choose int when…

  • The information is whole numbers
  • Accuracy matters: integers are exact
  • Counting things, like the number of siblings

Choose float when…

  • There can be fractional components
  • Numbers are very large or very small — the float range is much bigger
  • Prices and measurements, like $1.50 per orange
Why does the lecture warn about comparing floating-point numbers?
Because floats are approximations of real numbers, so results may not be exact
Because Python forbids the == operator on floats
Because floats can only store two decimal digits

The tailor needs calculations: how much fabric does a pair of pants need? tailor3.py combines the measurement variables into one expression.

total_fabric = ((hips_size + pant_size) * (thigh + pant))/10 print("total fabric: ", total_fabric)

With the lecture’s values (hips_size = 120, pant_size = 100, thigh = 28, pant = 139) the program prints total fabric: 3674.0 — note the .0.

bool and Truth Tables

The str Type and String Methods

Observations from Lab 1

Strings must be enclosed with single or double quotes. The backslash denotes the escape character for characters with special meaning — '\\' means a literal backslash. String concatenation uses the + operator and string repetition uses the * operator.

Strings are objects

A string of characters only makes sense when the characters are together: a string variable contains the memory address that contains all the characters. Because str is an object, you can perform many more operations on it using string methods.

MethodWhat it returns (lecture wording)

Returns a copy: every method above returns a copy of the string — the original string object is not changed. This matters in the Sandwich Maker activity, where the customer name is capitalized and the sandwich type is made upper case for the printed confirmation.

input() and Interactive Programs

So far our programs only push output to the user with print(). Programs are usually interactive — we need a way to get input from the user. The simplest form is text from standard input (the keyboard).

What input() does

The input() function reads a line from standard input (keyboard), converts it to a string, stripping the newline character. If a prompt argument is present, it is written to standard output without a trailing newline. The documentation example: s = input('--> ').

Output of input() feeds print()

The Echo activity’s hint: the output of input() is the input of print(). The anatomy of num = int('12345') is the same: function name, input, output — the result flows back into the assignment.

In tailor4.py the cost depends on the exchange rate, which only the user knows at run time:

FIXED_COST = 40 exchange_rate = input("Please give me the exchange rate Baba Yaga: ") total_cost = int((40 + total_fabric/100) * int(exchange_rate)) print("Total cost: ", total_cost, "Toman")

Entering 51000 prints Total cost: 3913740 Toman — but only because the reply was cast with int(exchange_rate) before the multiplication.

The user types 51000 when tailor4.py runs. What does input() hand back to the program?
The string "51000", which must be converted with int() before arithmetic
The integer 51000, ready for multiplication
A float, because exchange rates can have decimals

Output Formatting and f-strings

The tailor wants to print a sales table with neatly aligned columns. The lecture presents two approaches to make output more readable: formatted string literals (f-strings) and the string format() method.

f-strings

Prefix the string with f or F and include expressions inside the string as {expression}. Python evaluates each expression and splices the result into the text.

str.format()

Objects passed into str.format() replace the items in brackets — each placeholder {} is filled with the corresponding argument.

quantity = 1 print(f"{quantity:03d}") # prints 001

Format specification: you can specify the presentation format within the placeholder — here a width of 3 padded with zeros. The actual value is not modified during formatting; quantity is still the integer 1.

print(f"{customer_name}| {customer_id} |{hips_size:^5d}|{pant_size:^14d}|{thigh:^7d}|{pant:^12d}") print(f"total_cost: {total_cost:,d} Toman")
tailor5.py: :^5d centres the integer in a field five characters wide, and :,d inserts thousands separators — this is how the tailor lines up his table columns.

Recap: the print() signature

print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False) — print() concatenates different pieces of information with a single space as separation, controlled by the keyword argument sep. The tailor programs override it with sep=" ".

Lecture Summary

Variables name your data

A variable is a named container that makes data reusable, recallable and re-assignable — one edited assignment updates every use.

Part 1 focus

Know your types

A data type is a set of values plus operations. int is exact, float approximates, bool is True/False, and str is a sequence of characters.

Type discipline

Programs are interactive

input() reads a string from the keyboard, the program transforms it (often after casting), and f-strings or str.format() shape the printed result.
