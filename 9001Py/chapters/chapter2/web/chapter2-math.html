Variable Definition

Definition

A variable is a “named container” of data you would like to refer to in your program. Variables contain data so you can call it later, which makes the data reusable, recallable and re-assignable.

Why the lecture needs it

In tailor1.py every measurement was hard-coded text inside print() calls, so a change to the customer’s measurements meant editing every line. tailor2.py stores each measurement in a variable once, and every print() reuses the name.

According to the lecture, what is the simplest definition of a variable?
A named container of data you would like to refer to in your program
A keyword reserved by Python for special purposes

A set of values and a set of operations defined on those values. Primitive types use a fixed amount of memory, and in Python everything is an Object.

Type Casting

Explicit conversion

Conversion between data types invoked using function calls: str() converts to type str, int() converts into type int, and float() converts into type float. Anatomy of num = int('12345'): function name, input, output.

Implicit conversion

Python does the conversion automatically when appropriate. The lecture’s cases where results are implicitly converted to float: division between a float and int, division between two int, and addition between an int and float.

Conundrum: int or float

Accuracy: integers are exact but floating-point numbers are not. Range: if you are dealing with very large or very small numbers, you have to use float — its range is much bigger.

What is the type of the result of 7 / 2 in Python?
float — the lecture lists division between two int values as an implicit conversion to float
int — division always keeps the type of its operands

input() and Formatting

input() always returns a string

The input() function reads a line from standard input (keyboard) and converts it to a string, stripping the newline character. tailor4.py must cast the reply with int(exchange_rate) before doing arithmetic.

Output formatting

Two approaches: f-strings (prefix the string with f or F, expressions inside {expression}) and str.format() (objects replace the items in brackets). A format spec like {quantity:03d} prints 001; the actual value is not modified during formatting.

After quantity = 1, what does print(f"{quantity:03d}") display, and what is quantity afterwards?
It displays 001 and quantity is still the integer 1
It displays 001 and quantity becomes the string "001"
