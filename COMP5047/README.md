# COMP5047 Pervasive Computing Study Hub

Interactive bilingual study hub for **COMP5047 — Pervasive Computing** (S2 2026), built from the lecture decks, tutorials and readings in `Courses/COMP5047/`.

## What's inside

- `index.html` — course home page with Mission Control progress panel
- `chapters/chapterN/materials/` — the original lecture PDFs for that week
- `chapters/chapterN/web/` — study guide, foundations page and mind map per week
- `tools/` — knowledge graph, foundations graph, quiz hub, flashcards, progress dashboard
- `data/` — chapter manifest, quiz bank, flashcard deck, site metadata
- `shared/` — theme, language toggle config and chapter page chrome
