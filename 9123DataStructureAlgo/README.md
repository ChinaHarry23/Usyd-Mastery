# COMP9123 Data Structures & Algorithms Study Hub

Interactive bilingual study hub for **9123DataStructureAlgo** — Arrays, lists, trees, graphs, hash tables, heaps, sorting, searching and complexity analysis — with weekly guides, quizzes, flashcards and a concept graph.

Each week ships as a study guide, a foundations page, and a mind map, plus
five cross-course tools.

## What's inside

- `index.html` — course home page with Mission Control progress panel
- `chapters/chapterN/materials/` — the original lecture PDFs, notebooks and datasets
- `chapters/chapterN/web/` — study guide, foundations page and mind map per week
- `tools/` — knowledge graph, foundations graph, quiz hub, flashcards, progress dashboard
- `data/` — chapter manifest, quiz bank, flashcard deck, site metadata
- `shared/` — theme, language-toggle config and chapter page chrome
